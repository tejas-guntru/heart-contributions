# Heart Contributions

A pixel-art heart generated from dated Git commits for the GitHub contribution calendar.

## What is included

- 1,028 commits mapped across 140 days in 2024
- A heart-shaped contribution pattern
- A Windows PowerShell generator for reproducing the pattern

## Run it locally

From this repository directory:

```powershell
.\Create-HeartCommits.ps1
```

The commits use their author dates to create the calendar pattern. GitHub only displays them as contributions when the author email is verified on the account and the commits are on the default branch.
